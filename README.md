# AI_Prompts

AI_Prompts is a curated collection of useful AI/system prompts.

## Repository intention

This repository is meant to:
- Store prompt references that are practical and reusable
- Keep prompt content organized so new contributors can quickly navigate it
- Serve as a lightweight prompt library for future use

## What this repository does

- Collects and documents prompt content
- Provides a single place to maintain prompt resources over time

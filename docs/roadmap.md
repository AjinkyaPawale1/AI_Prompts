# Roadmap

- **More industries**: energy, telecom, public sector, education, real estate, logistics.
- **Eval harness**: golden sets per prompt, scoring (schema pass, exact/LLM-judge), regression reports in CI.
- **Provider adapters**: thin adapters for OpenAI, Anthropic, Azure OpenAI, Bedrock, local models, using native structured outputs.
- **Version policy in CI**: fail PRs that change a prompt without a version bump.
- **Notebook demo**: interactive walkthrough of the credit memo flow.
- **Catalog site**: searchable static site generated from the YAML.
